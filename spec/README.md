Los documentos de diseño tienen cuatro tipos de declaraciones:
- **Acordado:** sustentado por decisiones DEC-000x o por una autorización explícita.
- **Propuesto:** alternativa elaborada para debate; no vinculante para Codex.
- **Abierto:** requiere evaluación o decisión antes de congelar la especificación.
- **Fuera de alcance actual:** implementación, configuración local y pruebas de ejecución.

**Control de cambios:** Git conserva las revisiones; la semántica de aprobación se documenta en `docs/DECISIONS.md`.
